# NexaBuild video slots

Upload MP4 files here (the dashboard includes themed fallbacks when a file is missing):

- `intro.mp4` — first-connect intro screen
- `liquidglass-bg.mp4` — Liquid Glass global background
- `anime-1.mp4`, `anime-2.mp4`, `anime-3.mp4` — rotating Build module videos

Custom videos can also be selected in Settings → Kustomisasi video. Custom selections are stored locally in this browser/device.
